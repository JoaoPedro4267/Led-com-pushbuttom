# Led-com-pushbuttom

Este projeto foi desenvolvido na plataforma Wokwi utilizando 1 LED, 1 resistor, 1 push button e 1 half breadboard.

O funcionamento do circuito é bastante simples: quando o push button é pressionado, o LED vermelho acende instantaneamente. Assim que o botão deixa de ser pressionado, o LED é desligado imediatamente.

Esse projeto demonstra o funcionamento básico de um circuito digital com acionamento direto por meio de um botão, permitindo controlar o estado do LED de forma momentânea.
